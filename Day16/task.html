📚 Database Technologies Overview

RDBMS

RDBMS (Relational Database Management System) stores data in tables using rows and columns. It supports relationships between tables using Primary Key and Foreign Key. Examples: MySQL, Oracle, PostgreSQL.

SQL

SQL (Structured Query Language) is used to communicate with databases. It performs operations like Create, Insert, Update, Delete and Retrieve data.

MySQL

MySQL is a popular open-source Relational Database Management System. It is widely used for web applications because it is fast, secure and easy to use.

MySQLi

MySQLi stands for MySQL Improved. It is a PHP extension used to connect PHP applications with MySQL databases. It supports prepared statements and stored procedures.

PostgreSQL (PG)

PostgreSQL is an advanced open-source database. It supports complex queries, JSON, indexing and large enterprise applications.

Oracle

Oracle Database is a commercial RDBMS developed by Oracle Corporation. It is used in banking, healthcare, government and large enterprises.

Server

A server is a computer or software that provides services to clients. A database server stores, manages and processes database requests.

XAMPP

XAMPP is a free local server package. It includes Apache, MySQL, PHP and Perl. It is mainly used for PHP and MySQL development.

WAMP

WAMP stands for Windows, Apache, MySQL and PHP. It is used to create a local web server only on Windows computers.

GUI

GUI (Graphical User Interface) allows users to interact using buttons, windows and icons instead of typing commands. Example: MySQL Workbench.

MySQL Workbench 8

MySQL Workbench 8 is a graphical tool used to design databases, write SQL queries, create ER diagrams, manage users and administer MySQL servers easily.
